# Прихожая

Отдельная страница, которая всегда открывается мгновенно.

Бесплатный сервер Render засыпает после 15 минут тишины, и первый вход
упирался в его техническую заставку. Эта страница живёт на статичном хостинге
(GitHub Pages), поэтому просыпаться ей не нужно: она сразу показывает наш
экран загрузки, тихо будит сервер и передаёт управление приложению, как
только тот ответил.

Всё, что Telegram кладёт в адрес — подпись игрока, тема, параметр ссылки, —
переносится дальше без изменений: без этого приложение не узнает, кто пришёл.

## Как выложено

Отдельный публичный репозиторий `knb-launch`, GitHub Pages из ветки `main`.
Адрес этой страницы указан в BotFather как кнопка меню.

Публичным должен быть только он: внутри нет ничего, кроме вёрстки и адреса
сервера, который и так виден каждому игроку.

## Когда станет не нужна

На платном тарифе Render сервер не засыпает — тогда кнопку меню можно вернуть
прямо на адрес приложения, а эту страницу выключить.
