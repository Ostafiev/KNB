# Запуск в облаке (без своего компьютера)

Игра живёт на чужом сервере, адрес постоянный, компьютер можно выключать.
Всё бесплатно. Занимает минут двадцать один раз.

Два сервиса, оба без карты:

- **Neon** — база данных. Бесплатно и бессрочно, 0.5 ГБ.
- **Render** — сам сервер и Redis. Бесплатно, 750 часов в месяц.

Почему база отдельно: у Render бесплатная база умирает через 30 дней,
у Neon — живёт сколько угодно.

---

## Шаг 1. База данных

1. `neon.com` → **Sign up** → войти через GitHub
2. Создать проект: имя `knb`, регион **Europe (Frankfurt)**
3. На экране появится **Connection string** — скопировать целиком
   (вид: `postgresql://…@ep-….neon.tech/neondb?sslmode=require`)

Эта строка — адрес и пароль базы. Понадобится на шаге 3.

---

## Шаг 2. Файл настроек в репозиторий

В корне проекта лежит `render.yaml` — по нему Render поймёт, что создавать.
Его нужно отправить на GitHub:

GitHub Desktop → **Commit to main** → **Push origin**

---

## Шаг 3. Сервер

1. `render.com` → **Get Started** → войти через GitHub
2. **New** → **Blueprint**
3. Выбрать репозиторий `Ostafiev/KNB` → **Connect**
4. Render прочитает `render.yaml` и спросит три значения:

| Поле | Что вписать |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из @BotFather |
| `DATABASE_URL` | строка подключения из Neon (шаг 1) |
| `VITE_BOT_USERNAME` | юзернейм бота без `@`, например `knb_game_bot` |

5. **Apply** → сборка идёт минут пять
6. Когда статус станет **Live**, сверху будет адрес вида
   `https://knb-xxxx.onrender.com`

Проверка: открыть `https://knb-xxxx.onrender.com/health` — должно ответить
`{"ok":true,...}`.

---

## Шаг 4. Подключить к боту

@BotFather → `/mybots` → бот → **Bot Settings** → **Menu Button** →
**Configure menu button** → вставить адрес → текст кнопки, например `Играть`.

Адрес постоянный — вставляется один раз и больше не меняется.

---

## Доступ в админ-панель

Панель по адресу `<адрес сервера>/admin`. Вход по Telegram-аккаунту, пароля нет.

Чтобы пустить себя внутрь:

1. Render → сервис `knb` → **Environment** → **Add environment variable**
   Ключ `ADMIN_TELEGRAM_IDS`, значение — свой Telegram id (несколько через запятую)
2. **Save changes** — сервис перезапустится сам
3. @BotFather → `/mybots` → бот → **Bot Settings** → **Domain** → отправить
   адрес сервера. Без этого кнопка «Войти через Telegram» не появится

Свой Telegram id можно не искать заранее: откройте `/admin`, нажмите вход —
панель покажет его в сообщении «этот аккаунт не в списке администраторов».

## Как выкатывать изменения дальше

GitHub Desktop → **Commit to main** → **Push origin**.

Render это увидит и пересоберёт сам, минут за пять. Ничего нажимать не надо.

---

## Что важно знать про бесплатный тариф

**Сервер засыпает** после 15 минут без запросов. Первое открытие после сна
занимает около минуты — игрок увидит долгую загрузку. Дальше всё быстро.
Лечится платным тарифом (7 $/мес) — но только когда дойдём до живых игроков.

**Redis на Render теряет данные** при перезапуске. Сейчас это не важно:
в нём не хранится ничего постоянного. К этапу 4 (живые матчи) заменим
на постоянный — либо платный на Render, либо бесплатный Upstash.

**База в Neon засыпает** через 5 минут простоя и просыпается за секунду.
Данные не теряются.

**750 часов в месяц** — это чуть больше, чем часов в месяце, так что
одному серверу их хватает при любом раскладе.

---

## Если что-то пошло не так

Render → сервис `knb` → вкладка **Logs**. Там видно, на чём остановилось.
Прислать мне последние строки — разберёмся.

Частые причины:

- **`DATABASE_URL: Required`** — не вписана строка из Neon
- **сборка падает на `npm ci`** — не отправлен `package-lock.json` в GitHub
- **`Live`, но игра не открывается в Telegram** — адрес в BotFather
  вставлен без `https://` или с лишним пробелом

---

## Локальный запуск никуда не делся

`Запуск.command` продолжает работать. Он удобнее, когда нужно проверить
правку сразу: в облаке каждая сборка занимает пять минут, локально — секунды.
