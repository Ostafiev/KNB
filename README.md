# КНБ — Telegram Mini App

Игра «Камень, ножницы, бумага» на ставки внутриигровой валютой (медяки).

## Структура репозитория

```
frontend/           Telegram Mini App (React 19 + TypeScript + Vite + Tailwind v4)
backend/            Сервер: API, экономика, матчмейкинг (Node + Fastify + PostgreSQL + Redis)
docs/               Техзадание, чек-лист правок, исходный экспорт Figma Make
docker-compose.yml  Весь стек одной командой
```

Админ-панель живёт внутри `backend/` по адресу `/admin`: страницы собираются
на сервере, без отдельной сборки и внешних библиотек — панель должна
открываться и тогда, когда сломалось всё остальное.

## Запуск всего стека

Без Docker (работает на macOS 12+, где Docker Desktop уже не ставится) —
двойной клик по `Запуск.command`, либо руками:

```bash
brew install node postgresql@16 redis cloudflared
brew services start postgresql@16 && brew services start redis && createdb knb
cp backend/.env.example backend/.env      # вписать TELEGRAM_BOT_TOKEN и секреты
cd frontend && npm install && npm run build && cd ../backend
npm install && npm run migrate && npm run dev
curl http://localhost:3000/health
```

С Docker (macOS 14+, Linux-сервер):

```bash
docker compose up -d --build
```

Один образ собирает Mini App и сервер; сервер отдаёт приложение сам, поэтому
для проверки через туннель нужен один адрес. Миграции применяются при старте.

Пошаговая инструкция без предварительных знаний — в [ЗАПУСК.md](ЗАПУСК.md).
Объяснение каждой части простым языком — в [ЧТО-ПРОИСХОДИТ.md](ЧТО-ПРОИСХОДИТ.md).

## Запуск фронтенда

```bash
cd frontend
npm install
cp .env.example .env     # при необходимости поправить VITE_BOT_USERNAME
npm run dev              # http://localhost:5173
```

Другие команды:

```bash
npm run typecheck   # проверка типов
npm run build       # typecheck + production-сборка в dist/
npm run preview     # локальный просмотр собранной версии
```

### Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `VITE_BOT_USERNAME` | юзернейм бота без `@` — для реферальных и match-ссылок | `knb_bot` |
| `VITE_API_BASE_URL` | базовый URL backend API | `/api` |
| `VITE_DEV_BAR` | `off` — скрыть бар в dev; `on` — показать в собранной версии | не задана |

DEV-бар с кнопками переключения экранов включён в `npm run dev` и выключен в
`npm run build`. В production его место занимает обычный хедер с кнопкой меню.

Отдельно есть **review-сборка** — статическая версия с DEV-баром, чтобы
заказчик мог кликать по экранам без установки Node:

```bash
VITE_DEV_BAR=on npm run build -- --outDir dist-review
```

Переменную `VITE_DEV_BAR=on` в релизной сборке задавать нельзя.

## Архитектура фронтенда

```
src/
  App.tsx                   корневой роутер экранов и состояние матча
  main.tsx                  точка входа, оборачивает App в провайдеры
  index.css                 палитра (тёмная/светлая), Tailwind-токены, анимации
  types.ts                  общие типы (Screen, Choice, MatchConfig, RoundResult…)
  config/
    env.ts                  флаги окружения (DEV-бар, API URL, бот)
    economy.ts              параметры экономики из ЧАСТИ 5 + формулы Elo
  telegram/sdk.ts           обёртка над Telegram WebApp API (initData, locale, haptics)
  i18n/                     провайдер перевода + словари ru/en
  theme/ThemeProvider.tsx   переключение тёмной/светлой темы
  state/AppState.tsx        профиль, баланс, статистика, бонусы, рефералы
  lib/                      игровая логика (game.ts) и форматирование (format.ts)
  data/mock.ts              демо-данные до появления API
  components/               переиспользуемый UI (BottomSheet, кнопки, чипы, слайдер ставки)
  sheets/                   bottom sheet'ы (профиль, статистика, рефералы, приглашение…)
  screens/                  экраны приложения
```

### Тема

Все цвета объявлены рантайм-переменными `--tg-*` на `:root` и переопределены для
`:root[data-theme='light']`. Tailwind-токены ссылаются на них через `@theme inline`,
поэтому классы вида `text-tg-text` переключаются вместе с темой без перезагрузки.
Атрибут `data-theme` выставляет `ThemeProvider`.

### Язык

Определяется автоматически при первом входе: сохранённый выбор → локаль Telegram →
локаль браузера → русский. Ручной выбор в профиле имеет приоритет и сохраняется.

## Правки по «Правки V3» (вторая итерация)

| № | Правка | Как сделано |
|---|---|---|
| 1 | Руки в арене развёрнуты навстречу друг другу | `components/Hand.tsx`, поворот ±90° |
| 3 | Разворот применяется ко всем фигурам | там же, бой и результат раунда |
| 4 | Верхний бар на всех экранах | `components/TopBar.tsx` + `useAppChrome()` |
| 5 | «Друзья» открывает вкладку «Друзья» | `HomeScreen` → `OpponentsScreen initialTab` |
| 6 | Количество раундов в последних играх | `HomeScreen`, склонение через `formatRounds` |
| 7 | «Пополнить» открывает поп-ап | `sheets/TopUpSheet.tsx` (звёзды и TON, заглушка) |
| 8 | «Позвать» на карточке каждого друга | `OpponentsScreen` + `InviteSheet friend` |
| 9 | Раунды 1 / 3 / 5 / 7 / 9 | `ECONOMY.ROUNDS_OPTIONS`, только нечётные |
| 10 | Убран счётчик «N онлайн» | `OpponentsScreen` |
| 11 | Убран фильтр «1500+ pts» | `OpponentsScreen` |
| 12 | Убраны «142 в поиске» и «~8s» | `WaitingScreen` |
| 13 | Перед боем дважды вспыхивает «СТАРТ» | `BattleScreen`, 4 × 500 мс |
| 14 | «Следующий бой» и «Реванш» — разные кнопки | `SummaryScreen` |
| 15 | Убран пункт «Выйти из аккаунта» | `components/AppMenu.tsx` |
| 16 | «Пополнить» только в карточке баланса | `TopBar` показывает лишь число |
| 18 | Статистика раскрывается списком | `HomeScreen`, `StatsSheet` удалён |
| 19 | Блок начала игры поднят под профиль | `HomeScreen` |
| 20 | Бесплатная игра — только с друзьями | `ECONOMY.FREE_BET`, `BetSlider allowFree` |

Бесплатный матч не меняет баланс, рейтинг и счётчик сыгранных игр — иначе
порогом вывода можно было бы управлять бесплатными играми с другом.

Дополнительно из ЧАСТИ 5: rewarded-реклама на экране итогов, предложение
посмотреть рекламу при нехватке баланса, диапазон ставок 25–500, ручной ввод
ставки числом, расчёт Elo, порог вывода в статистике.
