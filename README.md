# КНБ — Telegram Mini App

Игра «Камень, ножницы, бумага» на ставки внутриигровой валютой (медяки).

## Структура репозитория

```
frontend/   Telegram Mini App (React 19 + TypeScript + Vite + Tailwind v4)
docs/       Техзадание, чек-лист правок, исходный экспорт Figma Make
backend/    (ЧАСТЬ 3 — ещё не реализовано)
admin/      (ЧАСТЬ 6 — ещё не реализовано)
```

## Запуск фронтенда

```bash
cd frontend
npm install
cp .env.example .env     # при необходимости поправить VITE_BOT_USERNAME
npm run dev              # http://localhost:5173
```

Другие команды:

```bash
npm run typecheck   # проверка типов
npm run build       # typecheck + production-сборка в dist/
npm run preview     # локальный просмотр собранной версии
```

### Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `VITE_BOT_USERNAME` | юзернейм бота без `@` — для реферальных и match-ссылок | `knb_bot` |
| `VITE_API_BASE_URL` | базовый URL backend API | `/api` |
| `VITE_DEV_BAR` | `off` — скрыть DEV-бар навигации в dev-сборке | не задана |

DEV-бар с кнопками переключения экранов существует **только в dev-сборке**
(`import.meta.env.DEV`). В production его место занимает обычный хедер с кнопкой меню.

## Архитектура фронтенда

```
src/
  App.tsx                   корневой роутер экранов и состояние матча
  main.tsx                  точка входа, оборачивает App в провайдеры
  index.css                 палитра (тёмная/светлая), Tailwind-токены, анимации
  types.ts                  общие типы (Screen, Choice, MatchConfig, RoundResult…)
  config/
    env.ts                  флаги окружения (DEV-бар, API URL, бот)
    economy.ts              параметры экономики из ЧАСТИ 5 + формулы Elo
  telegram/sdk.ts           обёртка над Telegram WebApp API (initData, locale, haptics)
  i18n/                     провайдер перевода + словари ru/en
  theme/ThemeProvider.tsx   переключение тёмной/светлой темы
  state/AppState.tsx        профиль, баланс, статистика, бонусы, рефералы
  lib/                      игровая логика (game.ts) и форматирование (format.ts)
  data/mock.ts              демо-данные до появления API
  components/               переиспользуемый UI (BottomSheet, кнопки, чипы, слайдер ставки)
  sheets/                   bottom sheet'ы (профиль, статистика, рефералы, приглашение…)
  screens/                  экраны приложения
```

### Тема

Все цвета объявлены рантайм-переменными `--tg-*` на `:root` и переопределены для
`:root[data-theme='light']`. Tailwind-токены ссылаются на них через `@theme inline`,
поэтому классы вида `text-tg-text` переключаются вместе с темой без перезагрузки.
Атрибут `data-theme` выставляет `ThemeProvider`.

### Язык

Определяется автоматически при первом входе: сохранённый выбор → локаль Telegram →
локаль браузера → русский. Ручной выбор в профиле имеет приоритет и сохраняется.

## Реализовано (ЧАСТЬ 2)

| № | Задача | Статус |
|---|---|---|
| 1 | Порядок фигур камень → ножницы → бумага | ✅ единый источник `lib/game.ts` |
| 2 | Счётчик «Раунд 1/3» на экране боя | ✅ + счёт по раундам |
| 3 | Реферальный бонус UI (+100 / +50 / 20 в день) | ✅ лист рефералов + ежедневный бонус на главной |
| 4 | Светлая тема | ✅ полная альтернативная палитра |
| 5 | Аккордеон последних игр | ✅ |
| 6 | Убрать «скорость анимации» | ✅ |
| 7 | Финальная фаза тряски рук (~400 мс) | ✅ `animate-shake-final` |
| 8 | Верхний бар только в DEV | ✅ `SHOW_DEV_BAR` |
| 9 | Кнопка «Показать статистику» | ✅ `StatsSheet` |
| 10 | «Позвать в игру» (ставка, раунды до 10, друзья) | ✅ `InviteSheet` |
| 11 | Условия пари только с друзьями | ✅ скрыты в случайном матчмейкинге |
| 12 | Автоопределение языка | ✅ |
| 13 | Экран согласия при первом входе | ✅ `ConsentScreen` |

Дополнительно из ЧАСТИ 5: rewarded-реклама на экране итогов, предложение
посмотреть рекламу при нехватке баланса, диапазон ставок 25–500, ручной ввод
ставки числом, расчёт Elo, порог вывода в статистике.
