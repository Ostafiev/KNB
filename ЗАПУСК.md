# Как запустить игру у себя и открыть её в Telegram

Инструкция для того, у кого на компьютере пока ничего не установлено.
Один раз занимает минут двадцать, дальше — две команды.

Всё будет работать **на твоём компьютере**: пока он включён и программа
запущена, игра доступна из Telegram. Выключил — перестала. Для проверки
этого достаточно; настоящий сервер понадобится ближе к запуску.

---

## Что понадобится установить

**Docker Desktop** — программа, которая поднимает игру со всем её хозяйством
одной командой. Скачать: `docker.com/products/docker-desktop`, установить,
запустить. В строке меню сверху появится значок кита — значит работает.

**cloudflared** — программа, которая делает из твоего компьютера временный
адрес в интернете. Без неё Telegram не сможет открыть игру.

Открой **Терминал** (Cmd+Пробел, напиши «Терминал») и вставь:

```bash
brew install cloudflared
```

Если ответит «command not found: brew», сначала поставь Homebrew:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

---

## Шаг 1. Настройки

Открой папку проекта (в GitHub Desktop кнопка **Show in Finder**).
Зайди в папку `backend`, найди файл `.env.example`, скопируй его и переименуй
копию в `.env` — без точки в конце, просто `.env`.

> Finder прячет файлы, начинающиеся с точки. Нажми **Cmd+Shift+Точка**,
> чтобы они появились.

Открой `.env` в TextEdit и впиши три вещи:

```
TELEGRAM_BOT_TOKEN=сюда токен от BotFather
ADMIN_SESSION_SECRET=любые случайные 40 символов
AUTH_TOKEN_SECRET=другие случайные 40 символов
```

Секреты можно не выдумывать — выполни в Терминале два раза и скопируй ответы:

```bash
openssl rand -base64 32
```

---

## Шаг 2. Запуск

В Терминале перейди в папку проекта. Проще всего напечатать `cd `, пробел,
и перетащить папку из Finder прямо в окно Терминала — путь подставится сам.
Затем:

```bash
docker compose up -d --build
```

Первый раз это займёт несколько минут: скачиваются составные части.
Дальше будет быстро.

Проверь, что живо:

```bash
curl http://localhost:3000/health
```

Должно ответить примерно так:

```
{"ok":true,"checks":{"postgres":{"ok":true},"redis":{"ok":true}}}
```

Если да — игра работает на твоём компьютере. Открой в браузере
`http://localhost:3000` и убедишься.

---

## Шаг 3. Адрес в интернете

В **новом окне** Терминала (первое не закрывай):

```bash
cloudflared tunnel --url http://localhost:3000
```

Через несколько секунд среди строчек появится адрес вида:

```
https://random-words-here.trycloudflare.com
```

Это и есть твой временный адрес. **Пока это окно открыто — адрес работает.**
Закроешь — перестанет, и при следующем запуске он будет другим.

---

## Шаг 4. Подключить к боту

1. В Telegram открой **@BotFather**
2. `/mybots` → выбери своего бота
3. **Bot Settings** → **Menu Button** → **Configure menu button**
4. Вставь адрес из шага 3
5. Напиши текст кнопки, например `Играть`

Теперь открой своего бота и нажми кнопку. Игра запустится внутри Telegram —
с твоим именем, твоим аватаром и балансом, который живёт на сервере.

---

## Как проверить, что сервер действительно работает

Признаки, что данные идут с сервера, а не выдуманы приложением:

- В профиле твоё настоящее имя из Telegram, а не «Никита Волков»
- Баланс ровно **100 медяков** — это регистрационный бонус
- Рейтинг **1000** — стартовый
- Нажми «Забрать» у ежедневного бонуса: станет 120. Закрой приложение,
  открой снова — останется 120
- Открой ту же ссылку на другом устройстве: тот же профиль и тот же баланс

Последний пункт — самая честная проверка. Раньше данные жили в памяти
браузера и на другом устройстве были бы другими.

---

## Что пока не настоящее

Соперники, список друзей и «Последние игры» по-прежнему выдуманы —
настоящие матчи появятся на этапе 4. Сейчас с сервера приходят:
профиль, баланс, рейтинг, бонусы, приглашения и параметры экономики.

---

## Ежедневный порядок

Включил компьютер и хочешь поиграть:

```bash
docker compose up -d
cloudflared tunnel --url http://localhost:3000
```

Новый адрес вставить в BotFather (шаг 4). Остановить всё:

```bash
docker compose down
```

Данные при этом не пропадают — они лежат в отдельном хранилище Docker.

---

## Если что-то пошло не так

**`docker: command not found`** — Docker Desktop не установлен или не запущен.
Проверь значок кита в строке меню.

**`Cannot connect to the Docker daemon`** — Docker Desktop установлен,
но не запущен. Открой его из Программ и дождись, пока кит перестанет мигать.

**`port is already allocated`** — порт занят другой программой.
Выполни `docker compose down` и попробуй снова.

**Telegram пишет, что приложение недоступно** — скорее всего закрылось окно
с `cloudflared`, или адрес в BotFather устарел. Запусти туннель заново
и вставь новый адрес.

**Что-то другое** — пришли мне вывод этой команды, там будет причина:

```bash
docker compose logs backend --tail 50
```
